## 비용 0원 재현 예제 — 정적 파트 국소 수정

예제 policy는 제품 규격이 아닌 정적 테스트 규격이며 과금 0이다. HARNESS의 fixture 생성/init/snapshot 후 Hair 위치 수정 명령을 수행한다. 상태의 이전 versions 파일을 그대로 보존하고 새 candidate만 변경됐는지 확인한다. `tests/test_harness.py`는 실제 GLB의 다른 노드와 바이너리 청크 보존을 검증한다. 기술 검사 전 deliver는 차단된다. 진짜 얼굴이나 헤어 품질 개선을 의미하지 않는다.

## 실제 Blender 검사 재현

승인된 Blender 실행 파일 절대경로를 `OMOTION_BLENDER` 환경변수로 설정하고 `python -m unittest discover -s tests -v`를 실행한다. 테스트는 자체 생성한 정적 큐브형 파트만 사용한다. 정상 모델, 열린 메시 실패, 허용 예외, 요구 규격 누락을 검증한다. Blender가 없는 환경에서는 명시적으로 skip된다. 리깅된 정상/오류 샘플, 실제 텍스처 누락, 관절/표정 변형 및 제품별 검사 기준은 별도 추가 필요하다.

## 외부 제작 실험

EX-01/02는 동일 원본에 대한 생성 비교, EX-03~06은 같은 초기 GLB 사본을 이용한 수작업 vs AI 기본 vs Harness 방식의 후처리 비교다. 각 후보의 실제 작업 ID, 모델/옵션, 생성/재작업 비용, 사람 작업시간, 비교 렌더 및 아티스트 승인 기록은 회사 내부 작업 폴더에만 보관한다. [PILOT](PILOT.md)의 동일 품질 기준을 따른다.
