# 처음 시작하기 — 디자이너용

## 먼저 작업 경로 선택

| 상황 | 선택 |
|---|---|
| 회사의 Charakuru 사용 권한과 VRM 1.0 적합성이 확인됨 | [경로 A: 원작자 키트](CHARAKURU-GUIDE.md) |
| 권한/포맷 미확인, 기존 Tripo 작업을 계속해야 함 | 경로 B: 기존 도구 |
| 이미 Blender 또는 3D 후보 파일이 있음 | B에서 생성 없이 수정·검수부터 |

기술 담당자는 [설치 및 연결](SETUP.md)을 지원한다. AI 도구의 실제 모델, 앱 권한, MCP, 이미지 생성, 브라우저 조작을 확인해야 한다. 일반 채팅에서 PC가 자동 연결된다고 가정하지 않는다.

## 경로 B — 기존 Tripo + Codex + Blender

1. 승인된 별도 로컬 작업 폴더와 원본 또는 기존 모델 사본을 준비한다. 외부 제공 허용 범위를 먼저 확인한다.
2. Codex 데스크톱에서 작업 폴더를 열고 Astra가 실제 선택 가능한지 확인한다. Tripo Studio 또는 공식 Plugin 중 하나를 선택한다.
3. 다음 요청을 보낸다. 자체 Skill을 사용하고 싶다면 기술 담당자가 이 저장소의 Skill을 프로젝트에서 사용할 수 있게 확인한 뒤 선택한다. 별도 원작자 폴더에 복제하지 않는다.

```text
현재 실제로 사용할 수 있는 이미지 생성, Tripo, Blender MCP, 화면 조작 기능을 확인해 주세요.
원본의 얼굴·헤어·체형·의상을 유지할 제작 계획을 제안해 주세요.
전신 생성과 머리·몸·헤어 분리 중 적합한 방식을 설명해 주세요.
먼저 계획과 비용 예상만 제시하고, 승인 전에는 유료 생성·외부 업로드·파일 수정·설치하지 마세요.
```

4. 승인된 경우 후보를 생성하고 정면·측면·후면에서 비교한다. 원하는 외형을 선택한다.
5. Blender에서 작업 사본을 열고 필요한 부분만 수정한다. [제작 예제](PRODUCTION-GUIDE.md)와 [검수 기준](QUALITY-GUIDE.md)을 참고한다.
6. 필요한 경우 리깅, 표정, 모션을 실제 확인하고 출력 파일을 대상 런타임에서 검증한다.

부분 수정 요청 예시:

```text
기존 얼굴은 보존하고 헤어와 목 접합만 수정하고 싶습니다.
원본과 현재 모델의 실제 모습을 비교하고 작업 계획을 보여 주세요.
승인된 사본에서만 수정하고 동일 시점·각도의 전후 결과를 확인해 주세요.
```

기존 생성 작업이 불확실하면 서비스의 작업 상태와 비용부터 확인한다. 결과가 이상하다고 전체를 자동 재생성하지 않는다. 사용한 도구와 파일 및 미해결 문제를 작업 폴더에 기록하고 다음 세션에서 이어간다.

처음에는 별도 ComfyUI, Hook, 자체 프로그램을 설치할 필요가 없다. 실제 작업에서 반복 문제가 확인되면 [도구 선택 기준](RECOMMENDATION.md)에 따라 추가한다.
