# 도입 지원 로드맵

이전 자체 Harness 개발 로드맵은 [기존 v0.1](https://github.com/shpark-omotion/3d-ai-workflow/blob/d59b321f3749481d2ad6e31659f19cd6f81d45e0/docs/ROADMAP.md) 및 [v0.2 Draft PR #1](https://github.com/shpark-omotion/3d-ai-workflow/pull/1)에 보존한다. 현재 범위는 다른 제작 팀의 기술 도입 지원이다.

| 단계 | 담당 | 완료 조건 / 상태 |
|---|---|---|
| R1 공개 리서치 및 가이드 | 기술 지원 | 공식 출처, 경로 A/B, 사용 예제 및 비교 기준 정리 |
| R2 도입 권한·제품 규격 확인 | 회사 담당자 및 3D 팀 | 회사 라이선스 적격/서면 허가, 실제 납품 포맷과 제품 요구 확정 / 미확인 |
| R3 초기 연결 | 기술 지원 | 승인된 환경에서 앱·MCP 읽기·사본 편집/재열기 등 확인 / NOT_RUN |
| R4 대표 캐릭터 실습 | 3D 팀 | 동일 목표 및 예산으로 비교, 품질·시간·비용 기록 / NOT_RUN |
| R5 보완 판단 | 공동 | 반복 문제에 필요한 최소 설정이나 활용 지침만 추가; 더 큰 개발은 별도 결정 |

R2가 차단되면 Charakuru의 업무용 실행을 하지 않고 기존 도구 경로 B를 검토한다. R3~R4는 실제 환경과 유료 생성 및 데이터 전송의 별도 승인 범위 안에서만 진행한다. 독립 검토는 추천 근거 및 가이드 적합성이 대상이며 실제 성과는 디자이너 파일럿으로 판단한다. 자체 플랫폼 완성은 종료 조건이 아니다.
