# 현재 제작 공정 및 개선 실험

## AS-IS 조사(실제 경험, 미사용은 미사용)

1. 캐릭터/소품/배경 중 사용 대상과 실제 사례(내부 승인 위치에만 기록).
2. 입력 레퍼런스 → Tripo → 후처리 도구 → 최종 제품까지 단계.
3. 생성 모델 그대로 사용한 범위와 형태·메시·UV·텍스처 수정 공수.
4. 몸 리깅, 모션, 얼굴 표정, 립싱크 각각 Tripo/다른 도구/수작업/미사용.
5. 기존 방식 대비 총 작업시간, 재생성·수작업·크레딧, 잘되는/어려운 유형.
6. 반복 결함, 아티스트 합격 기준, 가장 자동화하고 싶은 작업, 사용 중인 실제 AI·도구 환경.

실제 팀 답변 확보 전에는 회사의 공정/품질/생산성 수치를 확정하지 않는다.

## 비교 실험

동일 원본·동일 납품 품질 기준으로 A(기존 제작), B(현재 Tripo 활용), C(Tripo + Astra + Skill/AI 검수)를 비교한다. 가능하면 동일 후보 사본에서 B/C의 후처리를 비교해 생성 편차를 줄이고, 전체 제작시간도 별도로 기록한다. 첫 캐릭터는 실행 가능성 확인, 최소 3개 유형 비교 후 일반화 판단. 다른 모델/레퍼런스/숙련도/작업 순서는 기록한다. 품질 평가자는 방식에 따른 기대 편향을 줄일 수 있도록 가능한 경우 익명 비교한다.

| 항목 | A | B | C |
|---|---|---|---|
| 레퍼런스/생성/후처리/검수 단계별 사람 시간 | 미측정 | 미측정 | 미측정 |
| AI 처리 및 대기 포함 전체 소요 시간 | 미측정 | 미측정 | 미측정 |
| 생성/재생성 횟수와 실제 비용 | 미측정 | 미측정 | 미측정 |
| 원본 유지 특징별 일치 및 아티스트 판정 | 미검증 | 미검증 | 미검증 |
| 메시·텍스처·리그·표정/모션 | 미검증 | 미검증 | 미검증 |
| 실제 납품/런타임 적합 여부 | 미검증 | 미검증 | 미검증 |

성공 기준은 동일한 필수 품질 게이트를 만족하면서 수작업 시간 또는 전체 비용을 개선하거나, 동일 예산에서 품질이 개선되는 것. 구체 수치 목표는 기존 실측 후 결정. 품질 미달이면 빠르다는 이유만으로 채택하지 않는다.

## Tripo 협력 요구사항

실제 실패 사례만 기록: 사용 모델/옵션, 입력 유형, 작업 ID(공유 승인 범위), 재현 여부, 기대 결과, 관찰 결과, 후처리 비용, 필요한 Tripo 개선 및 내부 개선 가능 범위. 회사 정보 외부 공유 승인 필요. Skill로 해결 가능한 공정 문제와 생성 모델 자체 한계를 분리한다.
