# 현재 제작 공정 및 개선 실험

## AS-IS 조사(실제 경험, 미사용은 미사용)

1. 캐릭터/소품/배경 중 사용 대상과 실제 사례(내부 승인 위치에만 기록).
2. 입력 레퍼런스 → Tripo → 후처리 도구 → 최종 제품까지 단계.
3. 생성 모델 그대로 사용한 범위와 형태·메시·UV·텍스처 수정 공수.
4. 몸 리깅, 모션, 얼굴 표정, 립싱크 각각 Tripo/다른 도구/수작업/미사용.
5. 기존 방식 대비 총 작업시간, 재생성·수작업·크레딧, 잘되는/어려운 유형.
6. 반복 결함, 아티스트 합격 기준, 가장 자동화하고 싶은 작업, 사용 중인 실제 AI·도구 환경.

실제 팀 답변 확보 전에는 회사의 공정/품질/생산성 수치를 확정하지 않는다.

## 비교 실험

첫 실습은 B(팀의 기존 Tripo + Codex/Astra + Blender 경로)와 C(Charakuru 순정 경로)를 비교한다. A(기존 수작업)는 실제 기존 기록이 있으면 참고 기준으로 사용한다. C는 회사 사용 권한과 목표 포맷이 확인된 이후에만 실행한다. 동일한 승인 원본·보존 특징·납품 품질·예산 상한으로 비교하되 각각의 실제 모델·옵션·후보 수·숙련도·설치 공수·작업 순서 차이를 기록한다. 전체 제작 경로 비교와 동일 초기 후보 사본의 후처리 비교는 분리하며, 서로 다른 포맷/리그 때문에 후자가 불가능하면 이유를 기록한다. 첫 캐릭터는 실행 가능성 확인이며 일반화하지 않는다. 품질 평가자는 가능한 경우 제작 방법을 가리고 결과를 평가한다.

| 항목 | A | B | C |
|---|---|---|---|
| 레퍼런스/생성/후처리/검수 단계별 사람 시간 | 미측정 | 미측정 | 미측정 |
| AI 처리 및 대기 포함 전체 소요 시간 | 미측정 | 미측정 | 미측정 |
| 생성/재생성 횟수와 실제 비용 | 미측정 | 미측정 | 미측정 |
| 원본 유지 특징별 일치 및 아티스트 판정 | 미검증 | 미검증 | 미검증 |
| 메시·텍스처·리그·표정/모션 | 미검증 | 미검증 | 미검증 |
| 실제 납품/런타임 적합 여부 | 미검증 | 미검증 | 미검증 |

성공 기준은 동일한 필수 품질 게이트를 만족하면서 수작업 시간 또는 전체 비용을 개선하거나, 동일 예산에서 품질이 개선되는 것. 구체 수치 목표는 기존 실측 후 결정. 품질 미달이면 빠르다는 이유만으로 채택하지 않는다.

## 첫 실습에서 직접 할 일

1. 기술 담당자: 권한·포맷·실제 환경·테스트 원본·예산 상한 확인. 무료 로컬 연결/사본 편집 테스트부터 수행.
2. 디자이너: 각 경로에서 참조 → 후보 선택 → 조립/수정 → 필요한 리깅·표정·모션 → 출력/검수. 외형 변경과 유료 생성은 승인 범위 안에서만.
3. 부분 수정 사례: 얼굴·의상 유지, 앞머리/목 접합만 개선. 같은 각도에서 비교.
4. 동작 사례: 실제 요구가 있는 경우 눈 감기·미소와 걷기/팔 들기에서 관절·헤어·의상 검수. 실제 제품 런타임 확인은 별도.
5. 결과: 각 단계 사람 작업 시간과 대기 포함 전체 시간, 설치 공수, 실제 크레딧/AI 비용, 재생성·수동 수정 횟수, 보호 파트 및 필수 기술 품질, 파일 재개 및 사용 난이도 기록. 실제 수행하지 않은 항목은 NOT_RUN. 제품 규격 미정은 제품 합격으로 처리하지 않는다.

채택은 필수 디자인 및 제품 품질을 만족하고 사용 편의성/시간/비용 중 유의미한 개선이 확인된 경우에만 추천한다. 1회 결과만으로 생산성 향상을 일반화하지 않는다. 기존 포맷과 맞지 않거나 품질이 떨어지면 B를 유지한다. 데이터와 결과는 공개 Git이 아닌 승인된 내부 위치에 기록한다.

## Tripo 협력 요구사항

실제 실패 사례만 기록: 사용 모델/옵션, 입력 유형, 작업 ID(공유 승인 범위), 재현 여부, 기대 결과, 관찰 결과, 후처리 비용, 필요한 Tripo 개선 및 내부 개선 가능 범위. 회사 정보 외부 공유 승인 필요. Skill로 해결 가능한 공정 문제와 생성 모델 자체 한계를 분리한다.
