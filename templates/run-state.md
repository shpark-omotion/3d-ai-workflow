- 단계: PLAN / REFERENCE / GENERATE / DESIGN_REVIEW / REPAIR / TECH_QA / EXPORT_QA / APPROVAL

- 모델·도구 실제 확인 상태:
- 원본 파일/버전 및 보호 여부:
- 현재 작업본 / 마지막 승인본 / 수정 범위:

- 승인된 예산 / 실제 사용량 / 미확인 비용:
- 실패 유형 / 연속 실패 횟수:
- 검사 결과 및 증거 경로:
- 디자인 승인자 / 승인 범위 및 시간:
- 차단 원인 / 다음 행동:

- 검사 대상 버전/해시 및 변경 후 재검사 범위:
